# 同阅

**一个只读你自己导入的书、不联网找书的本地电子书阅读器。**
支持 Android 与 Windows。

[**下载**](../../releases) · [功能](#功能) · [你的书在哪](#你的书和数据在哪里) · [常见问题](#常见问题)

---

## 它是什么

同阅是一款**导入型**个人阅读器：你把手上的 EPUB、PDF、TXT 文件导入进来，它就变成一个干净、快速、不打扰的书架和阅读器。

它没有在线书城，没有书源，也不能下载书。你读到什么，完全取决于你导入了什么。

## 下载安装

### Android

1. 从 [Releases](../../releases) 下载 `androidApp-release.apk`
2. 手机上允许「安装未知来源应用」
3. 安装后直接打开

需要 Android 14 及以上。

### Windows

1. 从 [Releases](../../releases) 下载 `同阅-<版本>.msi`
2. 双击安装

安装包没有购买代码签名证书，Windows 可能提示「已保护你的电脑」。点「更多信息 → 仍要运行」即可。

## 开始阅读

**第一步：导入**

- **Android**：首页点「导入」从文件管理器选书；也可以在文件管理器里长按书 →「打开方式」→ 同阅，或从其它应用直接分享进来
- **Windows**：把书直接拖进窗口，或点「导入」

**第二步：读**

点开书就开始读。左右滑动翻页，点屏幕中间呼出控制栏，从章节抽屉跳章。

**第三步（可选）：多设备同步**

在「设置」里登录后，同阅会在后台同步你的阅读进度和书籍信息，换设备接着读。

不想登录也完全可以 —— 本地阅读不受任何影响。

## 功能

**书架**

- 搜索、分类标签、六种排序、列表 / 网格切换
- 置顶常看的书、继续阅读卡片
- 长按（Windows 上右键）可以改书籍信息或删除

**阅读**

- **EPUB**：按章加载，大书也秒开；翻页跟手，章节抽屉随意跳
- **PDF**：Android 有横向分页、纵向分页、连续纵向三种模式，可缩放、自动翻页、音量键翻页；Windows 是双页漫画式画廊，支持方向键和滚轮
- **TXT**：几百兆的单文件 txt 也不会卡

**整理**

- 封面、书名、作者、分类标签、简介都可以自己改
- 能从书籍文件里自动读出简介，并给出分类建议
- 自动分类是 **Beta**，默认关闭，需要你在设置里自己打开

**外观**

- 浅色 / 深色 / 跟随系统
- 多套配色；Android 支持跟随壁纸的动态取色
- 高对比度深色（夜间纯黑）

## 你的书和数据在哪里

**你导入的书、正文、封面，永远只留在你自己的设备里。**

登录同步时，同阅上传的只有：

- 账号信息（邮箱 + 加密后的密码）
- 书籍信息：书名、作者、文件哈希，以及你自己填的分类标签和简介
- 阅读进度：读到哪一章、哪一页

**不会**上传：书籍原文件、正文内容、封面图片。

另外：

- 不含任何第三方 SDK —— 没有广告、没有统计、没有崩溃上报
- Android 只申请「网络访问」一项权限
- 不申请存储、相册、通讯录等权限

## 常见问题

**支持哪些格式？**
EPUB、PDF、TXT。

**需要注册账号吗？**
不需要。不登录也能完整地导入和阅读，只是不能多设备同步。

**换设备了，阅读进度还在吗？**
登录同一个账号会自动同步。下载的正式版已内置同阅的同步服务地址。

**为什么 Windows 提示「已保护你的电脑」？**
因为安装包没有做代码签名。这是提示，不是病毒。

**有书签和笔记吗？**
暂时没有。客户端里还没有创建和查看它们的界面，所以当前版本不会产生这类数据，后续版本会补上。

**能在线找书或者下载吗？**
不能，也不会加。同阅只处理你自己导入的本地文件。

**书读一半关掉，下次能接着读吗？**
可以，阅读位置会自动保存。

## 给开发者

技术栈：Kotlin Multiplatform + Compose Multiplatform，本地存储用 SQLDelight，网络层用 Ktor Client。

```powershell
# Android 调试包
.\gradlew.bat :app:androidApp:assembleDebug

# Windows 直接运行
.\gradlew.bat :app:desktopApp:run

# Windows 安装包
.\gradlew.bat :app:desktopApp:packageMsi
```

需要 JDK 21 与 Android SDK；在 `local.properties` 里写 `sdk.dir=...`，或用 `ANDROID_HOME` 环境变量。

服务端地址是**构建期元数据**，不是应用内设置：

```powershell
.\gradlew.bat :app:androidApp:assembleRelease `
  "-Ptoread.serverBaseUrl=https://your-server.example.com"
```

留空则使用开发默认值（模拟器 `10.0.2.2:8080`，桌面端 `localhost:8080`）。自行构建的版本需要你自己的服务端才能登录同步。
