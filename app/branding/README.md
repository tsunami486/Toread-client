# 同阅品牌图标

“同阅”对外使用深靛蓝底色与展开书页图标。中央薄荷色书签表示在不同设备间延续同一阅读位置；图标不包含文字、云盘或在线书库意象。

透明前景母版 `tongyue-icon-foreground.png` 使用 Codex 内置图像生成工具生成，最终提示词为：

> 为“同阅”本地电子书阅读器创作原创、极简的应用图标：两张柔和弯曲的展开书页在中央书脊相接，形成统一连续的形状，并以负空间或中央书签表达共享阅读位置。采用扁平、圆润、强轮廓的矢量标志风格，使用纸白、浅长春花蓝和少量薄荷色；居中并保留充足安全边距，确保 16px 可辨识。不要文字、汉字、字母、云、手机、电脑、Wi-Fi、箭头、3D、阴影、水印或多余装饰。

背景主色为 `#4E5F9F`。安装 Pillow 后，在仓库根目录执行下面的命令即可从透明母版重新导出 Android 各密度图标、Android 自适应图标前景、Windows `.ico` 和桌面窗口 PNG：

```powershell
python client/app/branding/generate_icons.py
```

生成脚本不会修改 Android application ID、内部 Toread 工程标识或发布签名。
